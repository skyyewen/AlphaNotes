# 演示数据

本目录随仓库分发少量可公开的合成数据，用于验证工具调用、引用、人工确认和历史回放。未复制私人行情、策略或数据库。证券代码只测试系统映射，全部价格、量额和策略内容均为虚构示例。

## 内容与默认配置

| 内容 | 路径 | 规模 |
| --- | --- | --- |
| 合成日线 | `market/daily.parquet` | 3 个标的，每个 120 行，共 360 行，约 10 KB |
| 演示 Wiki | `strategy-wiki/` | 3 份规则、3 份虚构来源及版本/哈希登记 |

后端 `.env` 中的默认路径如下，无需下载完整行情：

```dotenv
STOCK_DAILY_PARQUET_PATH=../demo-data/market/daily.parquet
STRATEGY_WIKI_ROOT=../demo-data/strategy-wiki
```

相对路径由后端目录解析，因此在任何工作目录启动都指向仓库内的样本。日线和 Wiki 只读，运行生成的 RAG 索引与研究快照另存于被 Git 忽略的 `workbench-backend/data/`。

## 跑通一次研究

1. 按前后端 README 安装依赖，分别复制各自的 `.env.example`。
2. 在 **`workbench-backend/.env`** 填写 `DEEPSEEK_API_KEY`，必要时调整模型服务地址和模型名称。前端模板已启用本地研究 API。
3. 启动后端与前端，打开 `http://127.0.0.1:5173`。
4. 标的填 `601318.SH`（还支持 `000001.SZ`、`600519.SH`），资料与行情截止日均设为 `2026-10-28`，策略选择 `demo_combined_review / V1`。
5. 提交下面的问题，查看工具步骤和引用，确认归档，再从左侧历史记录打开快照。

> 这是合成数据演示。请读取最近 5 条日线和已选策略规则，说明观察结果、已有证据与缺失资料，并给出引用。基本面资料为空时明确说明未检出，不推测公司经营，不生成交易建议。

可选策略均为 `V1`：`demo_daily_review`（日线资料核对）、`demo_evidence_review`（资料引用核对）、`demo_combined_review`（多工具证据整理）。

## 样本边界

日线覆盖 `2026-05-14` 至 `2026-10-28`，日期仅排除周末，未扣节假日，不是真实交易日历。价格和量额由确定公式生成，不能用于回测或投资结论。生成方式与清单见 [行情说明](market/README.md)。

RAG 初始为空库，未放入虚构财报或私人资料。空库返回未命中属于正常结果，日线与 Wiki 仍可提供演示证据。展示 RAG 时可自行上传有来源的 Markdown；首次入库可能下载默认嵌入模型，命中检索后的重排需要 `SILICONFLOW_API_KEY`。AI 生成资料仍按现有规则排除事实检索。

本目录唯一允许提交的 Parquet 是 `market/daily.parquet`；其他行情、数据库、真实 `.env` 和依赖目录继续忽略。
